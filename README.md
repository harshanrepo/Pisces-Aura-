# Pisces Aura

A responsive product landing page for a luxury jewelry brand inspired by the Pisces constellation and ocean symbolism.

## Features

* Responsive design for desktop and mobile devices
* Fixed navigation bar with smooth scrolling
* Email subscription form with HTML5 validation
* Embedded product showcase video
* Interactive pricing cards with hover effects
* Custom typography using Cinzel and Poppins
* Luxury blue and gold color palette

## Technologies Used
